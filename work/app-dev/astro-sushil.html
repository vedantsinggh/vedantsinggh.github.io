The Problem

Commercial astrological platforms rely on third-party cloud APIs that introduce 800ms+ latency, fail without internet connectivity, and approximate planetary longitudes. Rendering complex geometric birth charts on mobile devices frequently causes UI frame drops and sluggish pan-and-zoom interactions.

Engineering Highlights

  • Offline Swiss Ephemeris C-Bindings: Compiled native C ephemeris libraries for on-device calculation of high-precision planetary longitudes, house cusps, and zodiac positions in under 50ms without network round-trips.
  • Hardware-Accelerated 60 FPS Canvas: Developed custom Flutter canvas painters dynamically rendering North and South Indian Kundali layouts with smooth touch zoom and multi-house transition animations.
  • Type-Safe Monorepo Architecture: Unified the Flutter mobile client with a Next.js administrative workstation using shared TypeScript and Dart data contracts over Prisma ORM and PostgreSQL.
  • Production Consultation Workflows: Built automated appointment scheduling, payment webhooks, and automated PDF astrological report synthesis.

Results & Release Status

Delivered sub-50ms offline planetary computations and fluid 60 FPS Kundali rendering across iOS, Android, and web platforms. The client application suite is currently undergoing pre-launch staging.
