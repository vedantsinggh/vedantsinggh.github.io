Astro Sushil Mobile & Web Suite

Production Vedic Astrology Platform with Sub-50ms Ephemeris Engine and Native Mobile Interfaces

Full-stack production platform combining a native Flutter iOS/Android mobile application, Next.js administrative workstation, and Prisma/PostgreSQL backend API. Built around an offline Swiss Ephemeris astronomical calculation core, it delivers sub-50ms planetary calculations and 60 FPS custom-painted Kundali charts.

Engineering Highlights
  • Cross-platform Flutter application with custom-painted 60 FPS canvas rendering North and South Indian Kundalis.
  • Offline Swiss Ephemeris C-bindings executing planetary longitudes and house cusps (Bhavas) in under 50ms without network round-trips.
  • End-to-end typed contract across Dart, Next.js, and Prisma ORM within an integrated monorepo architecture.
  • Production appointment booking workflows, payment webhooks, and automated PDF report generation.
